SLIDE ppt/slides/slide3.xml
Что такое LLM?
• LLM — Large Language Model, большая языковая модель.
• Обучается на больших объемах текстовых данных.
• Понимает запросы и генерирует текст.
• Может переводить, суммировать, анализировать документы и писать код.

SLIDE ppt/slides/slide5.xml
Как работает LLM?
• User Prompt → Tokenization → Transformer → Attention → Next-token prediction → Response
• Модель последовательно предсказывает наиболее подходящие токены с учетом контекста.
SLIDE ppt/slides/slide6.xml
Что такое токен?
• LLM работает с токенами, а не непосредственно со словами.
• Токеном может быть слово, часть слова, символ или знак препинания.
• Текст → Tokens → Numbers → Neural Network

SLIDE ppt/slides/slide8.xml
Self-Attention
• Self-Attention помогает модели учитывать взаимосвязи между частями текста.
• Механизм позволяет определить, какие элементы контекста наиболее важны для текущего шага.
