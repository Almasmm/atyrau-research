## Что проверено независимо

Команда из папки кейса: `python code/audit_revision.py --sources-dir ../research_notes/water --offline`. Зафиксировано **31 PASS, 0 FAIL**; подробности — `revision_checks_20260926.json`.

- Все 1095 дневных ячеек трёх PDF заново прочитаны PyMuPDF и сопоставлены с CSV. Основное извлечение использует другой движок, pdfplumber. Проверены пост 19802, единицы «см», ноль −30,00 м БС, страницы 35/35/37 и исходные SHA-256. Прежние 36 месячных контрольных сверок остаются действительными.
- Все девять признаков независимо восстановлены из семи строго предшествующих календарных дат для каждой из 1081 цели. Будущие измерения не обнаружены. Граница 2018–2019 непрерывна, разрыв 2020–2021 не пересекается. Размеры этапов — 358, 365, 358 целей.
- Скейлер финальной Ridge использует ровно 723 строки разработки; его средние совпадают со средними признаков 2018–2019. Параметры обеих сохранённых моделей совпадают с metadata, их прогнозы совпадают с test CSV. Выбор Ridge alpha=100 соответствует минимуму validation MAE.
- Все MAE, RMSE и R² восьми строк validation/test пересчитаны из сохранённых прогнозов. Ridge test MAE = 7,038741591 см; persistence = 6,966480447 см. Ни данные, ни параметры не подбирались заново по test.
- Реальный replay сохраняет 365 записей, 359 прогнозов и восемь статистических флагов. Порог 31 см получен только по непрерывным соседним датам 2018–2019; правило строгое `>`. Прогноз на 01.01.2023 не имеет фактической цели и не оценивается.
- Изолированный запуск создавался с dataset.csv, зафиксированным планом, контрольной таблицей извлечения и двумя научными скриптами. Предыдущие модели, predictions, исходные PDF и исследовательские кеши туда не переносились. Запуск из постороннего рабочего каталога завершился успешно; прогнозы совпали с исходными в допуске 1e-10. Полученные проверочные артефакты находятся только в исключаемой `_build/03_Water_Monitoring`.

Без `--sources-dir` аудит явно помечает независимое чтение PDF как NOT_RUN: полные оригиналы намеренно отсутствуют в распространяемом архиве. Для обычного повторного обучения достаточно включённого числового ряда; это не выдаётся за повторную загрузку источника.
