# Кейс №12: Урал — Атырау

Реальное исследование: 1095 среднесуточных уровней поста 19802 за 2018, 2019, 2022. Прогноз на один календарный день. Отбор по validation выбрал Ridge; test MAE 7.039 см против persistence 6.966 см. Улучшения по MAE нет (-1.04%).

Из папки кейса: `python code/pipeline.py` — обучение, оценка, графики и replay; `python code/pipeline.py --verify-only` — только проверка сохранённого результата; `python code/replay.py` — только повтор журнала; `python code/build_materials.py` — обновить русские тексты и slides.json; `python code/build_notebook.py` — выполнить Notebook из чистого kernel и экспортировать HTML. Нужны зависимости из общего requirements.txt. Рекомендуется активировать проектное окружение.

`python code/prepare_data.py --download --cache <папка-кеша>` скачивает отсутствующие публичные PDF и извлекает таблицы. Перед извлечением хеш каждого кешированного или скачанного PDF сравнивается с зафиксированным SHA-256 оригинала. При несовпадении возникает SourceIntegrityError с годом, URL, ожидаемым и фактическим хешем; dataset и manifest не перезаписываются. Изменение источника требует отдельной проверки и документирования, а не автоматической замены эталонного хеша. При отсутствии сети можно обучать по включённому числовому dataset.csv. SHA-256 исходных книг и точные страницы: data/source_download_manifest.json. Полные книги с неустановленной открытой лицензией не включаются в распространяемый архив.

Даты train/validation/test: 2018 / 2019 / 2022. Между 2019 и 2022 лаги не строятся. В 2019 допустим известный конец 2018; в 2022 первые семь дней — прогрев. Таблица targets: results/split_manifest.csv. Все модели оцениваются на одинаковых 358 test-днях.

Replay: 365 записей, 8 флагов при изменении больше 31 см; это статистический критерий из train+validation, не опасный уровень. Последний из 359 прогнозов относится к отсутствующей в наборе дате 01.01.2023 и не оценивается.

Ограничения: архивные гидропостовые наблюдения, тип автоматизации не подтверждён; live IoT отсутствует; 2020–2021 и последующие годы не исследованы; природа резких изменений не установлена; модели не доказали преимущество по основному критерию. Результаты получены с помощью ИИ, требуют личной проверки и понимания студентом; ложное самостоятельное авторство не заявляется.

Документы DOCX/PDF и презентации создаёт общий скрипт пакета из Report.md и slides_v2.json; slides.json сохранён как предыдущая версия. Новый контент презентации создаёт `python code/build_slides_v2.py`. Статус исходного IoT-кейса — PARTIAL: вычислительная часть проверена, но действующие датчики, передача и управление водой не подтверждены. Дополнительный аудит: `python code/audit_revision.py --offline`; результаты — results/revision_checks_20260926.json.
