# Журнал фактического выполнения

Дата выполнения: 25 сентября 2026 года. Детальные журналы отдельных экспериментов находятся в case/results и case/EXECUTION_LOG.md. Ниже записаны действия, действительно состоявшиеся, включая исправления.

1. Проверены пути курса, Assignment 1 и project. Начальная целевая папка не содержала пользовательских результатов. Исходные документы не перезаписывались. Текущая папка чата относилась к другому курсу, поэтому все результирующие пути заданы внутри нужного project.
2. Прочитан полный syllabus; два DOCX задания сначала возвращали PermissionError и sharing violation из Windows. Через WSL содержимое успешно извлечено в project/source_extractions. Затем оба документа прочитаны полностью. Дополнительные PPTX/PDF лекций извлечены локально; изучены релевантные методические и этические разделы, практическое занятие 2 и соседний PDF для разграничения задания. Страница 2 лекции 2,2 визуально проверена.
3. Сопоставлены расхождения нумерации заданий. Пользователь подтвердил, что выполняются четыре кейса, а PDF из assignment 2 относится к другому заданию. Матрица требований и AI disclosure сохраняют это уточнение. Установлен русский язык по syllabus.
4. Проверены реальные источники: семь архивов измерений воздуха и ERA5, три гидрологических ежегодника с локальным постом, COCO-разметка/изображения и разрешённый dashcam. Проверены альтернативные источники и ограничения доступа; обход авторизации не применялся. Ссылки, даты, хеши и лицензии сохранены.
5. Создан venv из поставляемого Python, установлены необходимые научные пакеты. После исключения user-site выявлен недостающий platformdirs; установлен внутри venv вместе с pywin32/colorama. Импорты и pip check прошли. Системный Python не изменён.
6. Выполнены четыре основных pipeline. Воздух: фиксированные временные границы, baseline/Ridge/Forest; вода: 2018/2019/2022 и replay; транспорт: группировка исходных изображений, majority/HOG+Logistic/Forest. Метрики и обученные модели сохранены. Слабые результаты не заменены тестом на train.
7. Выявлена несогласованность PM2.5/PM10 канала32. Основной опыт сохранён; добавлена явно разведочная вторичная станция235 с замороженными настройками, без выбора по её test. CSV загружается с round_trip для устранения пограничных различий float при повторном обучении деревьев; отчёт обновлён после окончательных метрик.
8. Notebooks выполнены в чистых kernels с реальными outputs, экспортированы HTML. Независимые проверки пересчитали метрики из predictions и лаги из исходных календарных рядов. Для воды проверены 36 месячных средних и реакция признаков на изменение будущих наблюдений. Тест не использован для настройки.
9. Подготовлены русские Report.md и slides.json; цифры берутся из результатов. Созданы DOCX и PPTX с заметками. Начальные проверки PPTX выявили шрифт Calibri у диаграмм, отсутствие embedded workbook и излишнюю числовую точность; генератор исправлен, значения диаграмм округляются явно, источник полной точности сохранён. Повторный экспорт с уникальным receipt устранил EEXIST при повторной проверке.
10. render_docx.py не нашёл LibreOffice. Word COM экспорт первоначально задерживался; исправлено имя переменной PowerShell и исключён отдельный вызов Repaginate. Завершены экспорты через Office. Останавливались только проверенные скрытые процессы, созданные данным конвертером; существующий пользовательский Word не завершался.
11. Визуальная проверка обнаружила повтор номеров рисунков и потерю пробелов между форматированными фрагментами. Генератор DOCX исправлен, отчёты пересозданы. Увеличены подписи редактируемых диаграмм. Проверены все страницы и слайды окончательных версий согласно visual_qa.md и QUALITY_CHECK.md.
12. Локальный HTML браузер открыть отказался из-за политики URL. Обход не предпринимался. Визуальный HTML просмотр отмечен NOT_RUN; чистые outputs, структура HTML и графики проверены. Demo прочитано декодером и просмотрено по реальным кадрам.

13. Первый общий запуск `--mode full --case all` выявил зависимость транспортного notebook от уже существующего столбца split. Подготовка данных очищала split, а ячейка EDA читала его до обучения. Запуск завершился с ошибкой KeyError; запись сохранена в reproduction_failed_initial.json. Порядок notebook исправлен так, чтобы разбиение создавалось до чтения; для водного notebook также явно закреплён Python kernel текущего окружения. После исправлений выполнен повторный общий запуск, результат которого указан отдельно, без сокрытия первого сбоя.

Общий повторный запуск и коды возврата команд записываются в `reproduction_run.json`. Итоговые проверки сохранены в `verification_results.json`; упаковка, исключения, CRC и хеши архива — в `QUALITY_CHECK.md` и `SUBMISSION_MANIFEST.csv`. Эти файлы отражают фактическое состояние, а не обещание будущей проверки.
