| Локальная выборка Атырау | Запрос поиска Atyrau dashcam vehicle annotated dataset не выявил проверенного разрешённого размеченного набора; пользовательского видео нет | BLOCKED: количественная локальная оценка |

Используется открытый HTTP-адрес COCO, опубликованный владельцем. HTTPS к images.cocodataset.org дал ошибку имени сертификата; проверка TLS не отключалась. Полная загрузка ZIP остановлена как избыточная. Вместо неё получен только instances_val2017.json через стандартные HTTP Range и zipfile с проверкой CRC. SHA-256 JSON сохранён в results/annotation_download.json. Все 337 JPEG открылись; ошибок скачивания 0.

Период: выпуск COCO 2017; date_captured сохранено как метаданные источника, но не трактуется как проверенное местное время съёмки. Частота нерегулярная, единица — объект на фотографии. География отдельных фотографий, тип камеры и поездка не заданы. Разметка категорий и рамок реальная; метки модели не заменяют эталон.

Лицензии изображений проверены по полю license исходного JSON: сохранены только 1,2,4,5 (CC BY-NC-SA, BY-NC, BY, BY-SA 2.0). NoDerivatives исключены. Все доступные сведения об атрибуции и оригинальные Flickr URL сохранены. Имена авторов и оригинальные названия отсутствуют в COCO JSON; запрос Flickr oEmbed завершился тайм-аутом. Эти отсутствующие сведения не придуманы. Для публичной публикации следует дополнить атрибуцию, где исходная страница доступна. Проект не опубликован.
