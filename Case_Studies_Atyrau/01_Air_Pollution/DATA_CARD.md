# DATA CARD: реальные архивные записи качества воздуха

Источник: AirData.kz, commit 0fe9a615baf614346e282796f685ce72b852187f; первичного поставщика Казгидромет. CC BY-NC4 поставщика. Копия LICENSE находится в 01_Air_Pollution/provenance; издатель ссылается на отдельный договор KGMT, текст которого независимо не доступен. Attribution: AirData.kz / Global Shapers Almaty Hub, https://github.com/qazybekb/AirDatakz-OpenData. Данные изменены фильтрацией городов/периода и суточной агрегацией.

Измерение: станция–час, опубликованное после QC поставщика. В dataset.csv кейса 1: станция–день–вещество; mean_ugm3 имеет диагностическое среднее даже при неполных сутках, value_ugm3 содержит target только при >=18 часов. Фиксированный период 2022-01-01…2025-12-31. Время интерпретируется по explicit offset и переводится в Asia/Atyrau; timestamps −07/−08 нуждаются в подтверждении первичного поставщика.

Все концентрации мкг/м³. Проверен коэффициент 1000 исходных mg/m³; AQI не использовался. Никакие target не восстановлены. raw сохраняет скачанные архивы и выбранные производные; results/download_manifest.csv содержит размер и SHA-256.

Частое PM2.5>PM10 и слабая вариация Актобе требуют сверки маркировки каналов/калибровки. Они не исправлены вручную и не исключены после просмотра test. Не установлена задержка публикации.

Выбор станций 32/22/31 фиксирован до обучения. Сравнение на 1124 общих датах, не населённостно взвешенное городское среднее. Данные не годятся для доказательства источников, правонарушений, индивидуального здоровья или безопасного оперативного управления.

ERA5 через Open-Meteo: сеточный реанализ температуры°C, влажности%, ветра м/с и осадковмм. Частота суточная, Asia/Atyrau; описание и SHA в results/weather_manifest.json. Реанализ используется только contemporaneous explanation, не как заранее доступный weather forecast.

## Повторная проверка одинаковых часов (26.09.2026)

Таблица исходного суточного контроля выше сравнивает средние по доступным часам каждого канала. В results/shared_hours_daily_quality.csv средние заново рассчитаны только по совпадающим часам (не менее 18 пар на сутки). На посту № 32 остаются 845/1209 несоответствий, в том числе 280 более 20%; на посту № 235 первоначальный единичный случай исчезает: 0/1300. Исходные значения не переписаны. Пороговое сравнение не заменяет поверку приборов.
