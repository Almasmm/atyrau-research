## Запуск

Из корня пакета: `python 01_Air_Pollution/pipeline.py --case 1`. Быстрая проверка существующих результатов: `python 01_Air_Pollution/pipeline.py --verify`. Полный повтор использует кеш raw, проверяет структуру и обучает модели; если кеш отсутствует, загружает публичные данные. Хеши для сверки: case1/results/download_manifest.csv.

Отчёт и презентация создаются общим генератором пакета из Report.md и slides.json; текст генерируется `python 01_Air_Pollution/build_content.py`. Notebook и HTML создаются `python 01_Air_Pollution/build_notebooks.py`. Модели нельзя считать проверенными для оперативных предупреждений.
