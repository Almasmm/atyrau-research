# Карточка данных — COCO vehicle crops

Исходный кейс №15. Статус PARTIAL: методическая классификация выполнена; репрезентативность для Атырау и качественная оценка полного dashcam-конвейера не установлены.

**Происхождение.** COCO Consortium, instances_val2017.json [V01–V03], фотографии Flickr, ссылка на каждую фотографию и её условия в results/image_attribution.csv. Учебное некоммерческое использование. COCO-аннотации CC BY4.0; лицензии самих фотографий различаются. Производные кропы сохраняют лицензию исходной фотографии, включая ShareAlike и NonCommercial там, где они указаны. Не приписывать CC BY4.0 всем изображениям.

**Единица:** один размеченный объект; source image_id определяет минимальную группу разбиения. Не видеокадр, не уникальный автомобиль, не поездка. Классы COCO: 3→car, 6→bus, 8→truck. Другие категории не сливаются с ними.

**Подготовка:** из 2632 исходных аннотаций трёх категорий оставлены 669 объекта в 337 фотографиях. Условия одновременно: разрешённая лицензия, iscrowd=0, ширина и высота рамки не менее 40 пикселей. Это фильтр качества изображения, который ограничивает применимость к дальним объектам. Неотобранных объектов: 1963; причины могут пересекаться, поэтому не суммируются как независимые категории. Все изображения скачаны, ошибок 0. Рамки обрезаются границами изображения с целочисленным округлением наружу. Полученные RGB PNG не аугментируются до split.

**Размеры:** 669 строк dataset.csv; пропусков в обязательных полях 0; ID объектов уникальны. Train403, validation133, test133. Групп по split: {'test': 64, 'train': 206, 'validation': 67}. Все классы представлены во всех частях. Исходная роль val2017 переопределена в этом небольшом эксперименте: это собственный split, не стандартная оценка COCO.

**Утечка:** группы по исходному изображению; дополнительно объединяются полные изображения с pHash distance≤6 и идентичные pHash кропов. Найдено 0 пар полных изображений по этому критерию. Фото, группы, точные копии кропов не пересекают split. Проверка не доказывает, что разные фотографы не снимали один объект/место: метаданных поездок нет. Предобученные веса не применялись.

**Переменные для модели:** 1813 числовых признаков из кропа: 1764 HOG,48 цветовых гистограмм,1 логарифм отношения сторон. Метка class не включена в признаки. ID, лицензии, путь, дата и география не подаются модели. scaler обучается только на train.

**Период/единицы:** bbox и разрешение — пиксели; вероятность/уверенность не публикуется как калиброванная. Фотографии нерегулярны; часовой пояс неизвестен, хронологический вывод невозможен. Нет подтверждения Атырау или типичного дорожного потока.

**Хранение:** raw/instances_val2017.json и raw/images — исходные данные; processed/crops — производные кропы; dataset.csv — индекс; processed/features.npz — признаки с ID. Скачивания, размеры, SHA-256 — results/download_manifest.json; SHA-256 кропа в dataset.csv. Manifest позволяет проверить целостность, но не подтверждает авторство фотографии.

**Demo:** raw/dashcam_urban_480p.webm, CC0 Fernost,2013. 30 секунд непрерывного видео плюс две явно обозначенные вручную выбранные области. Поле source_date содержит расхождение даты страницы и таймстампа кадра. Локальная метрика, mAP, трекинг, число уникальных машин и real-time не заявляются.
